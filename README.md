# Новый сайт СЭТТЭ (прототип)

Статический сайт без CMS: `index.html`, `styles.css`, `app.js`, `data.js`.
Заливается на любой хостинг как есть.

Внешние подключения: шрифты Google Fonts и библиотека плавной прокрутки Lenis (jsDelivr).
Без Lenis сайт работает, просто прокрутка будет обычной. Для хостинга в РФ шрифты и Lenis лучше положить локально.

## Слой эффектов (`fx.js`, `fx.css`)
Всё «вау» живёт отдельно от логики сайта и отключается целиком, если убрать две строки подключения из `index.html`.
При системной настройке «уменьшить движение» эффекты выключаются сами.
- Северное сияние — WebGL-шейдер в фирменных синих и золоте (первый экран и форма). Без WebGL — мягкий CSS-градиент.
- Первый экран — «занавес»: следующие блоки наезжают на него; смена фото — «врезка» наклонными ламелями под углом фирменного шеврона.
- Стек сцен: секция уходит вниз-в-глубину под следующую (о компании → проекты, портфолио → карта, контакты → подвал).
- Лента проектов — «долли»: номер, текст и фото едут с разной скоростью.
- Заголовки собираются по словам, подписи разделов «расшифровываются», цифры крутятся одометром.
- Дорога в разделе ДРСУ — SVG-трасса с золотой «фарой», едущей при прокрутке.
- Подвал — силуэт домов СЭТТЭ по этажности из `data.js`; окна зажигаются; строящиеся — золотым пунктиром. Клик открывает объект.
- Погода в Якутске на первом экране — живые данные open-meteo.com (без ключа); если сервис недоступен, строка просто не показывается.
- Карта объектов (`#geo`) — Leaflet + тайлы OpenStreetMap, затемнены CSS-фильтром под бренд. Для продакшена в РФ лучше
  перейти на Яндекс.Карты (нужен API-ключ) или собственный тайл-сервер: публичные тайлы OSM не предназначены для больших нагрузок.
- Координаты объектов — в `data.js` (`geo`). Собраны из 2ГИС-виджетов на sette.su и консенсуса трёх геокодеров (OSM Nominatim,
  Overpass, публичные карты). `approx: true` — здание не подтверждено, на карте показано пунктиром и подписано «примерно».
  **Перед публикацией сверить с отделом продаж** — особенно Гастелло, квартал 11, П. Алексеева 68/4, кардиодиспансер и сёла.
- Фирменный шеврон из гайдлайна — фон в «Направлениях» и подвале; свет за курсором на тёмных секциях; полоса прогресса.
- **Ход строительства (`#progress`)** — ежемесячные фотоотчёты застройщика из ЕИСЖС (наш.дом.рф): первая фотография каждого
  месяца, таймлапс, факты из карточки объекта (застройщик, плановый ввод, ключи, проектная декларация). Данные — в `data.js`
  (`progress[]`, `eisgs`, `pd`, `eisgsPlan`), собраны 30.09.2026. Фото грузятся с наш.дом.рф через их же resizer (проверено:
  отдаёт image/jpeg без авторизации). API ЕИСЖС закрыт анти-ботом и без CORS, автоматически обновлять из браузера нельзя:
  раз в месяц после размещения фотоотчёта добавить строку в `progress[]` (адрес фото — из карточки объекта) либо поставить
  серверный скрипт с реальным Chrome (описание в отчёте агентов). Скачать фото на свой хостинг — надёжнее.
- **Готовность (%)** — ЕИСЖС её не публикует; цифры в `readiness` вводит компания вручную (подпись «данные компании»).

Решения, которые нужны от заказчика по слою эффектов:
1. **Погода.** Бесплатный API Open-Meteo по условиям сервиса — только для некоммерческого использования. Для сайта продаж
   нужна подписка (customer-api.open-meteo.com) с указанием источника, либо убрать строку (одна функция в `fx.js`).
2. **Яндекс-карта в контактах** (iframe) при прокрутке до конца тянет ~20 МБ. Варианты: заменить на картинку-ссылку
   «Открыть в Яндекс Картах» или убрать — офис уже есть на карте объектов.
3. **Миниатюры.** Списки на телефоне грузят полноразмерные фото с sette.su (≈20 МБ за визит). После переноса фото
   на свой хостинг сделать превью 320×240 (`img/thumbs/`) и указать `thumb` у объектов в `data.js`.

## Как посмотреть локально
Открыть `index.html` в браузере или запустить в этой папке `python -m http.server 8765` → http://localhost:8765

## Что где править
- **Объекты, сроки сдачи, тексты, фото** — `data.js` (массив `OBJECTS`). Новый ЖК = новая запись со `status: 'building'`;
  когда сдан — поменять на `status: 'done'` и указать `year`. Цифры на сайте пересчитываются сами.
- **Дороги по годам** — `data.js` (массив `ROADS`).
- **Телефоны, адрес, вакансии** — `index.html`.
- **Цвета и шрифты** — начало `styles.css` (`:root`).

## Фирменный стиль (гайдлайн «СЭТТЭ», июль 2026)
- Палитра в `styles.css` → `:root`: акцентный синий `#1b36ff` (кнопки, всё кликабельное, акценты на светлом),
  глубокий синий `#132e5b` и чёрный `#151515` (тёмные блоки), золото `#b8943e` (акценты на тёмном — синий там не читается),
  градиенты из гайдлайна. Производные: светлый фон `#ecf2fa` (тон `#c0d4ee`), серый для подписей `#666`, красный — только ошибки формы.
- Логотип `img/logo-white.png` — белая версия «Инверсия», вырезана из PDF гайдлайна (стр. 4, ~575 px).
  Для чёткости на Retina и в печати нужен исходник SVG от дизайнера — заменить файл, имя оставить.
- Иконки вкладки: `img/favicon-32.png`, `img/apple-touch-icon.png` (белый знак на акцентном синем).
- В гайдлайне у «Глубокого синего» HEX `#132e5b`, а RGB указан 26/61/115 (= `#1a3d73`). Сайт следует HEX — уточнить у дизайнера.
- По гайдлайну фирменный шрифт — Manrope (заголовки Bold). Сейчас заголовки в Unbounded + Cormorant — решение за заказчиком.
- Папку `_old/` (прошлая медная версия стилей) на хостинг не заливать.

## Перед запуском в работу
1. **Фото** сейчас берутся с sette.su. Скачать `wp-content/uploads` со старого сайта в папку `img/`
   и заменить `BASE` в `data.js` на `'img/'`.
2. **Заявки**: без настройки форма открывает письмо на otdelprodazh-sette@mail.ru.
   Чтобы заявки приходили сразу — указать `SUBMIT_URL` в `app.js` (Telegram-бот, CRM или PHP-обработчик хостинга).
3. **Telegram**: на старом сайте ссылка «Мы в Telegram» пустая — нужен адрес канала.
4. Нужны политика обработки персональных данных (152-ФЗ) и Яндекс.Метрика.
5. Планировки и документы (ПД, РнС, РнВ) пока открываются по ссылкам на страницы старого сайта.
